## 3. 仮説（依頼の 10 観点）

| # | 観点 | 状態 | 結果 |
|---|---|---|---|
| 1 | 認証の回避 | ✔ | テーマに認証処理なし。カスタマイザーの権限は回避できない（統合テスト） |
| 2 | 他ユーザーのデータの取得・変更 | ✔ | 取得: **F-01**（他の会員のプロフィール）。変更: 寄稿者 B → 寄稿者 A は不可 |
| 3 | 権限昇格 | ✔ | GTM（生の HTML）への到達は `unfiltered_html` を持つ管理者のみ。寄稿者の入力から管理者の権限でスクリプトを動かす経路なし |
| 4 | SQLi・XSS・CSRF | ✔ | SQL なし。XSS は反射型・保存型とも不成立。CSRF は独自の書き込みエンドポイントがないため N/A（カスタマイザーは本体の nonce） |
| 5 | ファイル処理からの実行経路 | N/A | アップロード・ファイル書き込み・動的 include なし。テーマの PHP の直接実行は `ABSPATH` ガードで空 |
| 6 | SSRF | N/A | 外部通信なし |
| 7 | 型・形式による検証の回避 | ✔ | `?order[]=`・オブジェクト・NUL 文字・全角、GTM の配列・数値、ブロック属性の不正な値 |
| 8 | 正規操作の組み合わせ | ✔ | 親の非公開化（**F-03**）、投稿者の全記事の削除（**F-01**）、配置ミス → 報告書の公開（**F-04**） |
| 9 | プラグイン間の不整合 | △ | テーマ内の画面間の不整合を確認（**F-02**: 詳細ページは保護済み、一覧・OGP・JSON-LD は未保護）。実際のプラグインがないため、プラグインとの組み合わせは未検査 |
| 10 | テスト環境から本番への波及 | △ | テーマに環境切り替えのコードなし。配置ミス（F-04）と GTM の設定の持ち込みを運用リスクとして記載 |

## 4. 脆弱性が見つからなかった領域と検査の深さ

| 領域 | 検査の深さ |
|---|---|
| `inc/admin.php`（並び順） | コード精読、境界値、プロパティベーステスト、HTTP（反射） |
| `inc/assets.php`（ブロック） | コード精読、プロパティベーステスト 400 件（寄稿者の kses 下）、HTTP（寄稿者が保存した攻撃文字列） |
| `inc/customizer.php`（SNS・GTM） | コード精読、8 種類の利用者での保存の実測、変更セット経由、サニタイズの型、出力位置（HTTP） |
| `inc/security.php`（ヘッダー・XML-RPC・コメント） | コード精読、HTTP（ヘッダー、XML-RPC 3 種、コメント投稿 2 経路） |
| `inc/seo.php`（JSON-LD・OGP・パンくず） | コード精読、JSON の脱出のプロパティベーステスト、HTTP（検索・404・投稿者・保護投稿・階層ページ） |
| `single-interview.php`・`archive-interview.php` | コード精読、HTTP（寄稿者の攻撃文字列 17 キー＋目次・欄外メモ・URL、保護投稿） |
| `404.php`（dataLayer） | コード精読（既存の `tests/run.php` に Node.js で実行するテストあり） |
| その他のテンプレート・`js/` | コード精読（`js/interview-blocks.js` は編集画面用で、`save: () => null`。生の HTML を出力する API なし） |

## 5. 未実施の検査

| 項目 | 理由 | 実施する場合 |
|---|---|---|
| 本番・ステージングへの検査（非破壊のものを含む） | 対象と許可が未指定 | URL・許可範囲・負荷上限を指定して依頼 |
| 既知 CVE の照合（本体・プラグイン・PHP・Apache / Nginx） | 本番のバージョンが不明。外部の脆弱性 DB への照会もしていない | inventory のコマンドで取得したバージョンを、WPScan などで照合 |
| ログインしたクッキーでの HTTP テスト（会員 A / B・管理者） | パスワードの入力を避けた | テスト用アカウントの提供を受けて実施 |
| パスワードを入力済みの閲覧者（保護投稿の Cookie あり）の表示 | 修正案で「正しいパスワードの入力後はアイキャッチが出る」ことは未確認 | `wp-postpass_` の Cookie を生成して確認 |
| マルチサイト | 単一サイトで検証した | マルチサイトでサイト管理者が GTM を使えないことを確認 |
| Nginx・CDN・リバースプロキシ | 検証環境は Apache のみ | 本番の構成で F-04 の設定を確認 |
| ブロックエディター上の表示・ブラウザーでの実行 | DOM 解析で判定し、ブラウザーでは実行していない | ヘッドレスブラウザーで確認 |
| GTM の実コンテナ | テーマの外 | GTM 側の権限監査 |
| Mutation Testing ツール | 未導入 | 開発環境に Infection を導入 |
